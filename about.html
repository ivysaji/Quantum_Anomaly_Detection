About QADS Architecture

The Quantum Anomaly Detection System (QADS) is a hybrid cybersecurity framework combining classical telemetry metrics with IBM Qiskit quantum state simulations.

Pipeline Execution

  • Angle Encoding: Encodes telemetry values into qubit rotations (RY).
  • Entanglement Layer: Entangles adjacent qubits using Controlled-Z (CZ) gates.
  • Aer Simulator Execution: Runs circuits over 1,024 shots.
  • Entropy Analysis: Evaluates quantum measurement probability dispersion to flag anomalies.
